# Olga Sudareva Website

Professional website for Olga Sudareva.

Built with Jekyll and the al-folio academic website theme. The live site is deployed through GitHub Pages at https://olgasudareva.org.

## Main Content Files

- `_pages/about.md`
- `_pages/research.md`
- `_pages/teaching.md`
- `_data/socials.yml`
- `assets/pdf/Olga_Sudareva_CV.pdf`

## Deployment

Pushing to the `main` branch triggers the GitHub Pages workflow in `.github/workflows/deploy.yml`.
